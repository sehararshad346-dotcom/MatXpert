# MatXpert
Materials Engineering Intelligence

## About
MatXpert is an interactive materials engineering application
designed to assist students and engineers with material selection,
phase diagram analysis, engineering calculations, and learning.

## Features
- Material Selection Engine
- Phase Diagram Analysis
- Engineering Calculators
- Material Property Analysis
- Interactive Learning
- Engineering visualizations

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## How to Run
1. Install Python
2. Install requirements
3. Run MatXpert
